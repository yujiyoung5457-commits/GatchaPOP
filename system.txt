히어로 글자 순차 애니메이션 원리

1. IntersectionObserver가 .txtBox1 영역을 관찰한다.
2. 영역의 10%가 화면에 보이면 부모 요소에 on 클래스를 붙인다.
3. CSS는 .txtBox1.on 상태에서 각 자식 글자를 원래 위치로 이동시킨다.
4. 서로 다른 transition-delay 때문에 첫 번째부터 네 번째까지 차례로 실행된다.

- WELCOME: 왼쪽에서 이동하며 지연시간은 0초다.
- TO: 아래에서 올라오며 cubic-bezier의 1보다 큰 값으로 통 튀는 느낌을 낸다. 지연시간은 0.9초다.
- GATCHA: 오른쪽에서 이동하며 지연시간은 1.6초다.
- POP!: 위에서 내려오며 scale(0.25)에서 scale(1)로 커진다. 지연시간은 2.5초다.

opacity는 등장 전 0, 등장 후 1이라 이동 중 자연스럽게 나타난다.
observer.unobserve(entry.target)은 한 번 실행된 뒤 관찰을 끝내 반복을 막는다.
캡슐 3열 무한 자동 슬라이더 원리

1. .imgBox는 CSS Grid의 repeat(3, 1fr)로 왼쪽, 가운데, 오른쪽의 세 열을 만든다.
2. 각 .ball-lane 안에는 서로 독립적인 .ball-track이 있으므로 슬라이더가 총 3개다.
3. JavaScript는 각 트랙의 캡슐 이미지를 ball01.png, ball02.png, ball03.png 중 무작위로 정한다.
4. 각 열의 원본 .ball-slide-set을 복제해 바로 뒤에 붙인다.
5. 트랙이 위쪽으로 원본 한 묶음만큼 이동하면 같은 복제 묶음이 이어져 무한히 흐르는 것처럼 보인다.
6. SVG의 viewBox는 152.28 × 157.27이므로 이 비율로 캡슐 높이를 계산하며, 각 열의 창에는 정확히 3개만 보인다.
7. keyframes의 같은 위치를 일정 구간 유지해 잠깐 멈추고, 다음 구간에서는 캡슐 높이와 간격만큼 부드럽게 한 칸 이동한다.
8. 가운데 열은 반대 방향으로 움직이고, 각 열에 마우스를 올리면 그 열만 일시 정지한다.
SNS 제목과 상품 모달 원리

1. IntersectionObserver가 .maintext1을 감지하면 on 클래스를 붙인다.
2. 제목은 translateX(40rem)에서 시작하고 on 상태에서 translateX(0)이 되어 오른쪽에서 튀어나온다.
3. SNS 카드는 클릭뿐 아니라 키보드 Enter와 Space로도 선택할 수 있다.
4. 선택한 카드의 이미지, 제목, 계정과 설명을 읽어 product-modal에 넣고 showModal()로 연다.
5. X 버튼, 바깥 배경 클릭 또는 Esc 키로 모달을 닫을 수 있다.
6. dialog의 ::backdrop이 뒤 화면을 어둡게 만들고 모달에 집중하게 한다.
7. 데스크톱 모달은 상품 이미지를 왼쪽, 상세 정보를 오른쪽에 두는 가로형이며 position: fixed와 inset: 0, margin: auto로 화면 중앙에 놓인다. 모바일에서는 세로형으로 바뀐다.
검색 태그 입력칸 원리

1. + 버튼을 누르면 JavaScript가 새로운 input 요소를 만든다.
2. 만들어진 input은 + 버튼 바로 앞에 추가되어 기존 태그와 같은 줄에 배치된다.
3. tag-input 클래스로 기존 태그와 같은 분홍색 알약 모양 스타일을 사용한다.
4. 추가 직후 focus()를 실행하므로 바로 글자를 입력할 수 있다.
5. 현재는 입력만 가능하며 검색, 저장, 삭제 기능은 연결하지 않았다.
6. 기존 태그의 × 버튼을 누르면 closest()로 해당 tag-chip을 찾아 remove()로 화면에서 삭제한다.
